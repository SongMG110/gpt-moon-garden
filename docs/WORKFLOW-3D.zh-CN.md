# 人形、翅膀、长裙角色的建模与绑骨路线

## 我的建议

**长期应采用“先有可动画的人形底模，再定制外观和非人类部件”，不要把摆好姿态、衣裙翅尾融为一体的整块高模反复送去自动绑骨。**

这是根据当前模型检查结果给出的工程建议，不是某个服务保证一键达到参考图的承诺。当前两套模型继续用于静态展示；动作另做可编辑、轻量的制作版本。

## 为什么现在的路线不稳定

二维图生成的模型往往只有最终可见表面，身体、袖子、长发、翅膀和尾巴挤在一起。自动人体绑骨容易按空间位置把附近表面分配给手臂或腿，而不是按“这是一只翅膀”来理解。

当前文件的证据：66 个骨骼中没有翅尾独立骨链；抬左臂会带起同侧翅膀，权重图也显示相同影响范围；手指节点有骨骼但没有权重。

Adobe 的 Mixamo 官方 FAQ 明确要求可识别的人形头、躯干、四肢，中性姿态；额外翅膀、尾巴、厚重发型和服装、非对称姿态都可能导致自动绑骨失败。不同平台实现不同，这不能直接证明它们使用同一种算法，但说明这种输入本身就不适合盲目依赖人体自动绑定。

来源：[Mixamo 官方 FAQ](https://helpx.adobe.com/in/creative-cloud/faq/mixamo-faq.html)。

## 三条路线比较

| 路线 | 优点 | 局限与适用情形 |
|---|---|---|
| 现有图生 3D 模型继续修 | 最接近当前图片，静态展示立即可用 | 要分区、修拓扑、补骨链和权重；不能只更换自动绑骨平台 |
| **VRoid / 规范 VRM 人形底模，再定制外观** | 可编辑的人体结构，便于复用人形动作；脸、发型、材质可定制 | 要另外制作龙角、翅尾和复杂长裙；不会自动长得和参考图一样 |
| 借用已绑定模型后改造 | 可以较快验证动画和运行时 | 必须确认允许修改、再分发和用于开源项目；相似姿态不等于外观与拓扑可直接迁移 |

VRoid 官方提供体型、脸部、发型与纹理编辑，并可导出 VRM；这使它适合作为人形制作起点。它不是把现有 GLB 或参考图自动转换成同样外观、同样权重的万能工具。

来源：[VRoid Studio 官方介绍](https://vroid.com/en/studio)。

## “先绑骨，再外貌迁移”到底能做什么

1. **只改纹理**：衣服颜色、图案、眼睛颜色可以变化，几何和骨骼通常保留。但纹理不能新增真正的卷发、龙角、翅膀或裙摆体积。
2. **在同一拓扑上改形**：保留顶点关系时，可以保留已有权重作为起点；大改体型仍需调整关节和权重，并复测原有动作。
3. **换成全新的生成网格**：旧权重不会自动跟着过去。需要对齐姿态与体型，再转移顶点组/权重、修正接缝。转移只是初稿，不保证布料和非人类部位正确。

Blender 的 Data Transfer 和 Transfer Weights 可以在网格之间映射、插值顶点组/权重。文档要求正确的空间对应；权重转移不是角色语义识别。比较合适的用途是把人体权重转给贴身衣物，之后手工修正。

来源：[Blender Data Transfer](https://docs.blender.org/manual/en/3.6/modeling/modifiers/modify/data_transfer.html)、[Blender Transfer Weights](https://docs.blender.org/manual/en/5.4/sculpt_paint/weight_paint/editing.html)。

## 推荐的具体制作顺序

1. **先锁定人形底模与中性 A/T 姿态**，保留可编辑源文件、身体拓扑、标准人形骨架。先做抬手、屈膝、转头三个检查动作。
2. **按参考图定制脸、眼睛、发束、衣服**。生成的高模可做外观参考、重拓扑或贴图烘焙来源，不把百万面高模直接当最终桌宠模型。
3. **人体、服装、翅膀、尾巴、头发按部位组织**。不强制所有部件都拆成单独网格，但必须有清晰的顶点分区和独立控制范围。
4. 贴身上衣随躯干，袖子随手臂；**长裙用裙摆辅助骨，尾巴用多节骨链，左右翅膀分别设置翼根/翼中/翼尖**，不要给它们套最近的手臂或腿权重。
5. 人体动作可做重定向；主动拍翼、摆尾要额外制作动画。头发和尾部轻微惯性可考虑 Spring Bone，但弹簧效果不等于主动挥翅动作。
6. 眨眼、微笑、口型需要表情形变或可控制的眼睑/面部结构；人体骨架不会自动提供这些。
7. 每加一部分就复测同一组小动作：抬臂时翅膀应稳，抬腿时裙摆不应整片被拖走，转头时不应把远处衣服拉伸。

VRM 将人形、表情、视线和 Spring Bone 作为不同功能。可以用它组织运行时角色，但扩展部件的骨链和权重仍要自己做好。

来源：[VRM 设置说明](https://vrm.dev/en/vrm/how_to_make_vrm/setup_vrm/)、[VRMC Spring Bone](https://vrm.dev/en/vrm1/springbone/)。

## 借用别人的模型需要注意的实际条件

优先选择明确允许修改和再分发、能提供可编辑来源、具有干净人形骨架的底模。允许用于直播或渲染，不一定允许把模型文件附在 GitHub Release 供别人下载。

VRoid 官方预设不是 CC0；无特殊条款的内容允许许多修改、商用和分发用途，第三方素材仍按各自许可。若将来做“导出改造模型的角色生成器”，还要另看 VRoid 对这类应用的许可条件。当前项目只是展示已制作人物，不应把两种用途混为一谈。

来源：[VRoid Studio Guidelines](https://vroid.com/en/studio/guidelines)。

## 这次的落地决定

当前插件先提供 2D/3D、原画/Q版、PBR/纹理直显，不启用骨骼动作。保留所有旧模型与诊断页。后续先在人形制作版本上修好左翼和手臂的控制，再扩展尾链、裙摆和表情，避免同时追逐多种问题。
