# 架构与适配

## 三个相互独立的部分

1. `src/preview.html` → `scripts/build.mjs` → `preview/index.html`：可离线打开的界面演示。
2. `scripts/controller.mjs` + `manager/index.html`：仅绑定回环的 Node 本地管理器，保存用户配置并连接用户启用的 CDP。
3. `renderer/skin.js`：注入自己的 style 与 Shadow DOM 人物层。清理函数只撤销自己的对象，不刷新、不重写聊天内容、不修改原生 DOM 文本。

`skills/moon-garden/SKILL.md` 是可安装插件的管理入口。没有自动启动钩子，不会因安装就执行本地代码或应用皮肤。

## 热更新

控制器每约 2.5 秒读取本地资源哈希。图片或渲染器发生变化时，先清理上一版注入的样式、观察器、事件与计时器，再装载新版本。配置变更可立即应用。断开后重连仅连接已有调试接口，不启动或重启宿主。每个页面最多维护一个 CDP 会话。

控制器只读取自己放入 `globalThis.__gptMoonGarden` 的设置。人物反馈只观察“停止生成”按钮是否存在，不读取聊天文本。没有远程脚本、上报或自动执行下载内容的功能。

## 适配边界

CDP 发现只接受同一回环端口的 WebSocket 和 app:// 页面。渲染器需要 `main`、`[role=main]` 或输入控件之一；无法识别时返回失败。基础 CSS 使用常见语义容器和主题变量，可能被不同版本的原生组件覆盖。这不是对所有 Codex 版本的兼容保证。

实际宿主适配需另行验证：侧栏、消息卡片、代码、弹窗、浅深色、中文/英文停止按钮、缩放、高分屏以及窗口多开。本版测试覆盖独立预览、模拟原生 DOM、资源重载和恢复；尚未在用户当前 Codex 上开启并实测。

## 本地管理器

- 固定绑定 `127.0.0.1`，校验 Host，拒绝非回环 CDP 地址和重定向。
- 所有写操作要求同源 Origin 和每次启动随机的请求令牌。
- 配置采用白名单与数值范围校验，原子替换；没有任意文件读取 API。
- 静态资源按明确路径白名单提供。配置不接受 JS/CSS 或远程资源 URL。
- 用户手动替换本地渲染器代码意味着信任该版本。不要用调试接口执行来历不明的代码。
