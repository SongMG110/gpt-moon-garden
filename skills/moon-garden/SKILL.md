---
name: moon-garden
description: Preview, start, configure, diagnose or remove the GPT Moon Garden Codex desktop skin and companion. Use for this plugin's appearance controls; not for unrelated themes or generating new characters.
---

The plugin root is two directories above this skill. The runtime is self-contained Node.js 22+ code; no npm dependencies are required. Run `node scripts/controller.mjs` from the plugin root: it starts an independent background manager, waits for its health endpoint, prints the loopback URL and exits. `--foreground` explicitly keeps it attached to the current terminal. If system Node is absent, use an available bundled Node runtime. Windows users can double-click `Start.cmd`; no operating-system autostart entry is installed.

v0.2.0 supports `displayMode: '2d' | '3d'`, `character: 'portrait' | 'chibi'`, and `material: 'pbr' | 'texture'`. Setup downloads and verifies two static GLB assets (about 120 MiB total) from the fixed release manifest. Use `--skip-models` for 2D-only setup; retry `node scripts/install-models.mjs` if downloads fail. Models live outside versioned plugin caches; `MOON_GARDEN_MODELS_DIR` or the local data directory's `models-location.json` can choose another disk. Never put machine-specific paths in the public repository. Models are static; do not imply the known rigging issues or animations are fixed. The renderer runs through the existing debug connection without weakening host CSP. Model transfer goes through that connection; no network ports are exposed beyond loopback. In 3D mode drag the model to rotate and drag its caption to move it.

For a GitHub-marketplace installation on Windows, run `node scripts/setup.mjs` first when the user asks to configure the computer. It copies only this plugin's maintained runtime files to `%LOCALAPPDATA%/GPTMoonGarden/app`, registers the limited current-user **on-demand** task `GPTMoonGarden.Manager`, starts and verifies it, and creates a `GPT Moon Garden` desktop shortcut. No boot/logon/timer trigger is installed, no password/admin elevation is requested, and Codex is never terminated. This avoids relying on children of an agent terminal surviving the host's exit. If task registration is blocked, report that concrete error; do not change execution policies or system protections.

- For a preview, open `preview/index.html` using the app's file/browser panel. No live client connection is necessary.
- For activation/configuration, run the manager and open its printed URL. Installation alone does not apply a skin. When the user requests activation, `node scripts/activate.mjs` or `Enable.cmd` starts the manager, connects to an existing CDP workspace and applies. On Windows, if Codex is closed, the launcher can open it with loopback CDP first; if Codex is running without CDP, it refuses and asks for a normal user-initiated exit. It never kills the app.
- For diagnostics, run `node scripts/controller.mjs --doctor`. A missing CDP endpoint is a setup condition, not a reason to kill or restart the host. `docs/INSTALL.md` explains a dedicated launcher for a later natural app launch.
- Read `docs/SETUP.zh-CN.md` when guiding a person who installed from GitHub. Do not send them into a versioned plugin cache directory or imply installation enables CDP. If the plugin is old, refresh the `moon-garden` Git marketplace and reinstall the same plugin with the documented Codex CLI before setup.
- Do not report activation from a successful manager start. Verify `/api/status` has `config.enabled=true` and `status.applied>0`. If it is only reachable, say the manager is running but the skin is not applied.
- For updates, replace the installed `assets/`, `theme/` and `renderer/` files with the selected trusted release. The controller notices changes and reinjects visuals while preserving local appearance choices. Updating controller/plugin code itself needs a controller restart or plugin reload. Do not promise zero-restart host upgrades.
- For restoration, use Restore in the manager. Only this plugin's styles, DOM and listeners are removed. Never overwrite Codex settings, conversations, account data or installation files.

The manager connects only to a user-enabled loopback CDP endpoint. Never terminate ChatGPT/Codex, change its startup arguments while it is running, expose a debug port to a network, or apply the skin when the request was only for preview/publication. Do not copy credentials into the project. This is an experimental community skin adapter, not an official global-theme extension API. Use `docs/ARCHITECTURE.md` when changing integration behavior.
